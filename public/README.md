# Public Assets

Place your static files here:

- `resume.pdf` - Your resume (required for download button to work)
- `og-image.png` - OpenGraph image for social sharing (optional, 1200x630px recommended)
- `favicon.ico` - Favicon (optional)

## Adding Your Resume

1. Export your resume as PDF
2. Name it `resume.pdf`
3. Place it in this `public/` folder
4. The download button on /resume will automatically work
