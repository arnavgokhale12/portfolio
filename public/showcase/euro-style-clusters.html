Euro Style Clusters

Playing style classification + MoneyBall transfer efficiency for Europe's top 5 leagues

A full data science pipeline that clusters 16 years of European soccer teams into distinct playing styles using k-means and hierarchical clustering, then cross-references spending data to rank clubs by transfer market efficiency — like Moneyball, but for football.

Python scikit-learn Streamlit Pandas SQLite K-Means / Hierarchical Clustering PCA / t-SNE

Overview

What it does & who it's for

Euro Style Clusters ingests match statistics for the Premier League, La Liga, Serie A, Bundesliga, and Ligue 1 from 2008–2024 and groups teams into named playing style clusters (e.g. "Possession Attackers", "Direct Play", "Ball Controllers") using unsupervised machine learning.

A second MoneyBall module pulls transfer market data from TransferMarkt and computes efficiency metrics — squad value per euro spent, net spend, ROI — to identify which clubs extract the most value from their investment and which just throw money at the table.

Built for sports analysts, football researchers, data science portfolios, and anyone interested in the intersection of tactical analysis and sports economics.

Feature Highlights

Core capabilities

🔬

Unsupervised Style Clustering

K-means with silhouette-score optimal k selection plus hierarchical (Ward linkage) clustering on team-season feature vectors. Supports k=3–8 clusters adjustable via the dashboard slider.

💰

MoneyBall Transfer Efficiency

Computes value_efficiency = squad_value / total_spent for every club in the dataset. Ranks smart spenders vs. big spenders and shows which clubs overachieve relative to outlay.

🔍

Team Style History Search

Search any club to trace their style evolution across seasons — did Man City shift clusters when Guardiola arrived? Did Leicester's 2016 title team belong to a unique cluster?

📐

Multi-Source Feature Engineering

Match-level stats are unpivoted from home/away format to team-centric, XML event columns parsed for shots/crosses/corners, then aggregated to team-season level across four feature groups: attack, possession, defense, game state.

🗺

PCA / t-SNE Visualizations

Cluster projections in 2D PCA and t-SNE space with radar charts per cluster, enabling qualitative interpretation of what each cluster's playing style actually means.

📤

Interactive Streamlit Dashboard

6 tabs: Overview, Team Search, Timeline, Leagues, MoneyBall, Export. League and season filters, team financial profiles integrated with style cluster data, CSV export of cluster assignments.

Why It Matters

Technical depth & practical value

The pipeline handles real-world data quality challenges: three heterogeneous sources with different team naming conventions (requiring a cross-dataset team_mapping.py module), different available features across time periods (full features 2008–2016, reduced features 2016–2024), and XML event columns embedded in the SQLite database that require parsing to extract shot/cross/corner counts.

The MoneyBall analysis operationalizes a genuine sports economics concept — identifying which clubs are Moneyball-style over-achievers vs. which simply outspend rivals. Athletic Bilbao's 4.2× efficiency emerges naturally from the model without being hand-coded, demonstrating that the features genuinely capture what the analysis intends to measure.
