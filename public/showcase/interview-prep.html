Interview Prep

Terminal-based Anki-style flashcard system for Data Science & Quant Finance interviews

A zero-dependency Python CLI that implements a five-tier spaced repetition priority queue for DS, ML, econometrics, and quantitative finance flashcards — so you always study the gaps interviewers exploit, not the things you already know.

Python 3.10+ Zero external dependencies Spaced Repetition CLI / Terminal JSON persistence

Overview

What it does & who it's for

Interview Prep is a terminal flashcard application that surfaces the right card at the right time. Before every session, all cards are sorted into five priority tiers based on status and accuracy — new cards first, then review (incorrect since last streak), then struggling cards, then learning cards, and mastered cards last. Progress persists to JSON after every card so you never lose a session.

The card database covers four categories tailored for Data Science and Financial Economics interviews: machine learning (bias-variance tradeoff, regularization, gradient boosting, transformers/attention), econometrics (OLS assumptions, IV, DiD, panel data, unit roots), quantitative finance (ARIMA, GARCH, CAPM, BSM, Greeks, MPT), and quant brain teasers (Jane Street / Citadel style probability and logic puzzles).

Built for any candidate preparing for roles at hedge funds, quant trading firms, data science teams, or financial economics research positions.

Priority System

Five-tier spaced repetition

PriorityStatusCondition
1 — First new Never seen before
2 review Answered incorrectly since last correct streak
3 learning Seen ≥1 time, accuracy < 70%
4 learning Seen ≥1 time, accuracy ≥ 70%
5 — Last mastered Seen ≥3 times and accuracy ≥ 80%

Feature Highlights

Core capabilities

🧮

Priority-Sorted Sessions

Every session re-ranks all cards before starting. You always encounter your weakest cards first, not random order. Answering incorrectly immediately moves a card back to Priority 2.

🎯

Category Filtering

Study all categories together, or target one specifically: python3 study.py -c quants. Perfect for the morning before an interview at a quant fund.

💾

Mid-Session Persistence

Progress is written to progress.json after every single card. Quit at any point without losing data. Tracks seen count, correct count, status, and last seen date per card.

📊

Progress Dashboard

Run python3 study.py --stats to see a session summary: cards by status, accuracy per category, total sessions, and mastery breakdown.

🔧

Zero Dependencies

Pure Python 3.10+ stdlib only. No pip, no virtualenv, no setup. Clone the repo, run the script. New card categories are auto-discovered — just drop a JSON file in data/.

📝

Easily Extensible

Adding a new card requires only a unique id, question, and answer in the appropriate JSON file. No code changes. Auto-discovered by the script.

Why It Matters

Practical value

The insight behind this tool is simple but important: cramming everything is less effective than drilling the specific cards you're weakest on. The five-tier priority system operationalizes that: your review queue (cards you've gotten wrong) gets all the attention, mastered cards are pushed to the end, and new cards are always introduced before you waste time on things you already know.

The domain coverage is deliberately narrow and curated — not a general-purpose flashcard app, but a targeted tool for one specific interview preparation context where the gaps are known in advance: OLS assumptions, IV, GARCH, Black-Scholes Greeks, Jane Street probability puzzles.
