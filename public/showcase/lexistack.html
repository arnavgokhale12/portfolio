Overview

What it does & who it's for

LexiStack presents a daily set of vocabulary words, deterministically selected using an FNV-1a seeded hash so the same date produces the same words across all devices. Users navigate a learn → quiz → review cycle, with each answer recorded against a three-level mastery system (new → learning → mastered) and a numeric 0–3 mastery level.

The app's standout feature is deep iOS integration: home screen and lock screen widgets display the current word and update in real-time as the user navigates through their daily session. Widget interactions (Got It / Repeat buttons) trigger iOS 17 App Intents that update progress in shared App Groups UserDefaults and reload the widget timeline.

Built for vocabulary learners who want passive reinforcement throughout the day — seeing a word on their home screen multiple times per day without opening the app.

Feature Highlights

Core capabilities

🍎

Real-Time iOS Widget Sync

Home screen and lock screen widgets update instantly when the user navigates to a new word — via a React Native → Swift native module bridge writing to App Groups UserDefaults, followed by WidgetCenter.reloadAllTimelines().

🎮

Interactive Widget Buttons (iOS 17)

Widget buttons trigger Swift App Intents (GotItIntent, RepeatIntent) that update progress in shared storage and load the next word — all without opening the app.

🧠

Spaced Repetition + Mastery Tracking

Three-level string mastery (new → learning → mastered) plus a numeric 0–3 level updated by a simple clamp rule. Daily sessions mix new words with review words prioritized by age and mastery.

🎯

Placement Test + Difficulty Bias

Onboarding placement quiz estimates user vocabulary level (1–5). Daily word selection is then biased 70% toward the user's comfort zone, 20% stretch words, 10% other — using deterministic seeded selection.

🏆

Lexi Levels Gamification

Five progression levels (Bronze → Diamond) based on total mastered words. Progress bar, level badge, and weekly goal calendar displayed on the home screen, updating immediately after each session.

📚

Custom Lists

Users can create custom word lists (up to 20 words each) and mix them into their daily session. Mix count is configurable (0–5 custom words per day), blended deterministically with the seeded word selection.

Why It Matters

Technical depth & iOS engineering

The iOS widget integration is non-trivial: it requires a native Swift WidgetKit extension, a React Native native module bridge in Swift, App Groups entitlements for shared storage, and iOS 17 App Intents for interactive buttons — none of which are handled by Expo's managed workflow and had to be manually configured in Xcode.

The widget target was added manually (Expo prebuild would delete it), worked around a CocoaPods + Xcode 16 objectVersion incompatibility, resolved macOS extended attribute code signing failures, and handled physical device widget quirks around Face ID lock screen and containerBackground modifiers.
