Supply Chain Dashboard

Composite stress index + regime-conditional market overlay for supply chain risk

A full-stack macro intelligence tool that aggregates 7 economic indicators into a composite supply chain stress index, classifies the current market regime, and shows how equities and ETFs historically perform under each regime — connecting macro signals to portfolio decisions.

FastAPI SQLAlchemy + Alembic Streamlit FRED API NY Fed GSCPI yfinance SQLite

Overview

What it does & who it's for

The Supply Chain Dashboard ingests 7 macroeconomic indicators from authoritative sources (NY Fed, FRED, Cass Freight, Baltic Dry Index) into a local SQLite database, normalizes each using a 36-month rolling z-score, and combines them into a single weighted composite index. The composite is classified into four regimes: low, normal, elevated, crisis.

A market overlay pulls equity price data via yfinance and computes regime-conditional return statistics for major indices, sector ETFs, and key stocks — letting a user see "when supply chain stress is elevated, how does XLI (Industrials ETF) historically perform?"

Built for macro analysts, portfolio managers, finance students, and anyone tracking supply chain disruption risk with market implications.

Feature Highlights

Core capabilities

📊

Dynamic Composite Index

Configurable N-indicator composite: each indicator has weight, invert_sign, and include_in_composite flags stored in DB. Z-score normalization over a 36-month rolling window. Weighted average with regime thresholds.

📈

Regime-Conditional Market Returns

Pre-computes avg monthly return, std dev, and sample count for SPY, sector ETFs (XLI, XLY, XLK, SMH), and key stocks (NVDA, AMZN, COST) under each of the 4 supply chain regimes.

🏗

Full REST API

FastAPI backend with typed Pydantic schemas: composite latest/history/indicators, market series, price history, regime returns, and current prices — all fully documented at /docs.

🗄

Persistent Time Series DB

SQLAlchemy models with Alembic migrations store economic observations, market prices, and pre-computed regime return statistics — enabling fast dashboard load without live API calls.

🌐

Streamlit Dashboard

Status banner showing current regime + composite score. Left panel: composite score history chart + all indicators. Right panel: market impact with S&P 500, ETFs, and regime context. Bottom: key stocks by theme.

⚙️

Modular Ingestion Scripts

Separate ingestion scripts per data source (GSCPI, Cass, FRED, Baltic Dry, yfinance) allow selective re-ingestion without touching other indicators. Regime analyzer runs as a separate post-processing step.

Why It Matters

Business value & technical depth

Supply chain disruptions have had measurable equity market impact — COVID-era port congestion, chip shortages, and freight cost spikes all corresponded with sector-specific equity drawdowns. This tool operationalizes that relationship: rather than monitoring each indicator separately, it synthesizes them into a single actionable regime signal, then surfaces which equities have historically responded most to that regime.

The composite index formula mirrors how institutional analysts think about macro risk aggregation — z-score normalization removes unit differences between indicators, rolling windows adapt to structural shifts, and configurable weights allow analyst judgment to be baked into the model rather than hard-coded.
